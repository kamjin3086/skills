# Palworld Answer Examples

Use these as style calibration. Replace sources and facts with freshly verified results; do not copy example facts blindly.

## Example 1: Small Factual Answer

User: “阿努比斯采矿几级？”

```text
结论：阿努比斯的采矿适应性是 X 级。

依据：
- 数据库/图鉴页显示阿努比斯的工作适应性包含 Mining X。

来源：
- [结构化数据源链接]（查询时间：YYYY-MM-DD）
```

Keep this short. Do not turn it into a build guide unless asked.

## Example 2: Practical Base Recommendation

User: “我 35 级，想建矿场，哪些帕鲁比较好抓又能采矿搬运？”

```text
结论：优先考虑 A / B；如果你已经能稳定去更危险区域，再考虑 C。

依据：
- 数据事实：A 有采矿 X、搬运 Y；B 有采矿 X、搬运 Y。
- 获取难度：A 通常比 C 更容易获得；C 更强但偏中后期。
- 玩法推断：矿场同时需要采矿和搬运，所以不只看采矿等级，也要看搬运和获取成本。

不确定/需确认：
- 我没有读取你的存档；如果你已经解锁某区域或已有飞行坐骑，推荐顺序可能会变。

来源：
- [结构化 Pal 数据源]
- [地图/位置来源]
```

Avoid listing every possible Pal. Give a short ranked recommendation.

## Example 3: Location / Coordinate Question

User: “朱雀在哪里抓？给坐标。”

```text
结论：朱雀主要在 ... 区域可找。精确坐标以地图源显示为准。

位置：
- 地图源显示 ... 附近有刷新/出现点。
- 如果地图只给区域而非坐标：我不能可靠给出具体坐标；建议在地图筛选中选择 Suzaku/朱雀查看点位。

注意：
- 地图数据更新时间：...

来源：
- [互动地图链接]
- [朱雀图鉴/百科链接]
```

Never invent coordinates.

## Example 4: Version / Patch Question

User: “1.0 后阿努比斯削了吗？”

```text
结论：官方更新记录中 [有/没有] 明确提到阿努比斯的削弱。当前可确认的是 ...

依据：
- 官方 patch notes：...
- 当前数据库/图鉴页：...

不确定/需确认：
- 如果削弱来自隐藏数值或未写进 patch notes，需要对比数据表或社区实测，不能只凭传言确认。

来源：
- [Steam 官方更新]
- [结构化当前数据源]
```

Official source determines whether a patch claim was announced; structured data helps explain current values.

## Example 5: Conflicting Sources

User: “某帕鲁现在采矿到底是 3 还是 4？”

```text
结论：暂时采用 X 级，置信度中等。

冲突：
- 来源 A 显示 X。
- 来源 B 显示 Y。

采用理由：
- 来源 A 更新时间更接近当前版本 / 是结构化数据库 / 与官方改动一致。

建议：
- 如果这会影响培养决策，进游戏图鉴或查看最新数据源再确认一次。

来源：
- [来源 A]
- [来源 B]
```

Do not hide conflicts.

## Example 6: Weak Evidence

User: “现在最强词条是什么？”

```text
结论：如果目标是 ...，常见推荐是 ...；但这是玩法建议，不是固定事实。

依据：
- 数据事实：相关属性/技能影响 ...
- 社区经验：多个指南倾向于 ...

不确定/需确认：
- 最强词条会随用途、版本、队伍和配种成本变化。

来源：
- [机制/图鉴来源]
- [近期指南/社区来源]
```

Label subjective advice clearly.
