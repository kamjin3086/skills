# Palworld Question Types

Use this when a user asks a mixed or practical question.

## Base / Work Recommendation

Examples:

- “35级建矿场用哪些帕鲁？”
- “前期会采矿和搬运的谁好抓？”
- “据点冷却和搬运怎么配？”

Process:

1. Extract constraints: player level, biome, available Pals, work type, difficulty tolerance, solo/server.
2. If constraints are missing but the answer can proceed, state assumptions instead of asking many questions.
3. Query/verify Pal work suitability and relevant stats.
4. If acquisition difficulty matters, check location/source pages.
5. Give tiers:
   - easy/early
   - midgame
   - late/endgame
6. Mark facts vs recommendations.
7. Prefer a short ranked list over a long exhaustive list.

## Pal Detail / Comparison

Examples:

- “阿努比斯适合据点吗？”
- “企丸王和阿努比斯谁更适合挖矿？”

Process:

1. Verify both Pal records.
2. Compare work suitability, food, movement, combat relevance, availability if asked.
3. Answer with a short recommendation for the user’s context.

## Location / Route

Examples:

- “朱雀在哪里抓？”
- “火山哪里硫磺多？”
- “帮我找刷优质帕鲁油路线。”

Process:

1. Use map/location sources first.
2. Report area names and coordinates only if source provides them.
3. Include map update date if visible.
4. If route planning needs the user’s level/base location, ask one concise follow-up or give assumptions.
5. If exact coordinates are unavailable, provide “how to find it on the map” instead of making up coordinates.

## Patch / Current Version

Examples:

- “1.0 阿努比斯削了吗？”
- “最新版本新加了哪些帕鲁？”

Process:

1. Search official Steam/Pocketpair.
2. Use SteamDB as secondary build/update tracking.
3. Use database/wiki only to explain current resulting data.
4. Include exact date/version/build if available.

## Breeding / Calculator

Examples:

- “怎么配出阿努比斯？”
- “这两只配种结果是什么？”

Process:

1. Prefer a calculator/database that exposes breeding outcome.
2. If exact pair requested, verify both parent names.
3. If multiple routes exist, give a practical route and cite the calculator/source.
4. Do not fabricate formulas unless verified from a trusted source.

## Drop / Material Source

Examples:

- “优质帕鲁油哪里刷？”
- “聚合物需要什么材料？”
- “哪个帕鲁掉火药？”

Process:

1. Verify item name and likely English/internal name.
2. Use structured item/drop pages first.
3. If the user wants efficiency, combine drop sources with location/acquisition difficulty.
4. Separate “drops from” from “best farm route”.
5. If the answer depends on map spawn density, use a map source or label as recommendation.

## Passive / Build Advice

Examples:

- “阿努比斯适合什么词条？”
- “据点帕鲁被动怎么配？”
- “战斗坐骑用什么被动？”

Process:

1. Confirm whether the goal is base work, combat, mount speed, breeding, or mixed use.
2. Verify relevant Pal role and skills/stats.
3. Use guide/community sources only as advice, not hard fact.
4. Give a compact build:
   - must-have
   - good alternatives
   - avoid / low priority
5. State if recommendations may vary by version or playstyle.

## “Can You Just Tell Me?” Mode

If the user sounds frustrated or wants a quick answer, do not over-research. Use the minimum reliable source set, answer first, then include a short “需要更精确的话我会再查地图/版本” note.
